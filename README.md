# Yu-Gi-Oh Banlist Tier List

A tier list of every hit and pointed card across Genesys, TCG, OCG, Master Duel and Duel Links, tagged by why the card is restricted (Stun/Floodgate, Handloop, Summoning Lock, FTK, Turn Skip, Combo Slop).

Open `index.html` to view. Card images live in `images/`.

Fan project. Yu-Gi-Oh! and all card names and artwork belong to Konami.
